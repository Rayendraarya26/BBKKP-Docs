# ⚙️ 05 — Operations Documentation

Folder ini berisi panduan setup lokal, manajemen variabel lingkungan (*environment*), dan alur deployment ke server produksi/staging.

## Sub-direktori:
* **`setup/`**: Panduan instalasi dependensi lokal.
* **`environment/`**: Daftar variabel `.env` dan konfigurasi server.
* **`deployment/`**: Panduan deployment dan CI/CD pipeline.
