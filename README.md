# 📚 BBKKP Systems Documentation Repository

Repositori ini berisi seluruh dokumentasi teknis, spesifikasi produk, arsitektur sistem, aturan pengkodean, dan rencana pengembangan untuk ekosistem aplikasi **BBKKP (Balai Besar Kulit, Karet, dan Plastik - Kementerian Perindustrian RI)**, termasuk **BBKKP Polimer** dan **BBKKP SIS**.

---

## 🗺️ Panduan Navigasi Dokumen

Gunakan **[INDEX.md](INDEX.md)** sebagai peta navigasi utama (*Map of Content / MOC*) untuk menemukan dokumen yang Anda butuhkan.

### Ringkasan Struktur Folder (`docs/`):

* **[`docs/01-product/`](docs/01-product/_index.md)** — Kebutuhan produk, FRD (Functional Requirement Document), dan riset pengguna.
* **[`docs/02-architecture/`](docs/02-architecture/_index.md)** — Arsitektur sistem, analisis modul, skema database, dan spesifikasi API/integrasi.
* **[`docs/03-decisions/`](docs/03-decisions/_index.md)** — Architecture Decision Records (ADR) untuk mencatat keputusan teknis penting.
* **[`docs/04-standards/`](docs/04-standards/_index.md)** — Standar pengkodean, keamanan, dan SOP Git Dual-Remote Workflow.
* **[`docs/05-operations/`](docs/05-operations/_index.md)** — Panduan instalasi lokal, environment variables, dan deployment.
* **[`docs/06-tasks/`](docs/06-tasks/_index.md)** — Milestone proyek, roadmap integrasi, dan rincian sprint.
